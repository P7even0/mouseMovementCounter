# Mouse Tracker

A simple C program that tracks raw mouse movement on Windows, including when the application is running in the background.

I created this project as a utility to make development easier for another project I'm working on in a private repository.

## Features

- Tracks raw mouse movement using the Windows Raw Input API.
- Records cumulative X and Y movement.
- Supports background mouse tracking.
- Displays the accumulated movement in the application's window title.

## Technologies

- C
- Windows API (Win32)
